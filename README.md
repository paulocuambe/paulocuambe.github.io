# Paulo Cuambe's blog

Markdown content, vanilla HTML/CSS, and Hugo. No theme or package installation required. Code blocks use Arborium on demand with Ayu syntax colors and JetBrains Mono.

- Preview: `hugo server -D`
- Build: `hugo --minify --panicOnWarning`
- Posts: `content/posts/`
- About: `content/about.md`
- Styling: `static/style.css`
- Settings and social links: `hugo.toml`

See [publish.md](publish.md) for GitHub Pages setup and writing instructions.
